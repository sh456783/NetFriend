# Screenshots

이 폴더는 **NetFriend 프로젝트 구현 과정과 결과를 시각적으로 참고하기 위한 이미지 모음 폴더**입니다.  

설계 전용 문서나 알고리즘 설명을 위한 자료라기보다는,  
**실제로 구현한 구조와 화면을 한눈에 확인할 수 있도록 정리한 참고용 캡처 자료**입니다.

---

architecture  
- NetFriend 전체 시스템 구성도  
- 하이브리드 서버(On-Premise × AWS EC2) 구조  
- EC2 보안 서버 및 Suricata IDS 동작 흐름  
- IDS 탐지 → 로그 생성 → 웹 대시보드 연동 구조
- 
---

dashboard  
- FastAPI + React 기반 웹 대시보드 실제 구현 화면  
- IDS 이벤트, CPU 메트릭, IP 차단 관리 UI  
- 서버 상태 및 보안 이벤트 통합 모니터링 화면  

---

physical_server  
- 온프레미스 물리 서버 서비스 실행 화면  
- VPN(StrongSwan) 연결 상태 확인  
- 내부 서버 시스템 상태 확인 화면  

---

본 이미지는  
프로젝트의 **전체 구조를 빠르게 이해하거나**,  
발표·문서·설명 시 **구현 결과를 보조하는 참고 자료**로 활용하기 위해 정리되었습니다.

각 이미지에 대한 상세한 설명이나 설정 과정은  
상위 디렉터리의 README.md 및 기능별 문서를 참고하면 됩니다.
