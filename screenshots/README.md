# Screenshots

이 폴더는 **NetFriend 프로젝트의 실제 구현 결과 화면**을 정리한 자료입니다.  

각 이미지는 다음과 같은 내용을 포함합니다.

architecture  
- 전체 시스템 아키텍처 구성도  
- 하이브리드 서버 및 IDS / IPS 동작 흐름 다이어그램  

dashboard  
- FastAPI + React 기반 웹 대시보드 화면  
- IDS 이벤트, CPU 메트릭, IP 차단 관리 UI  

physical_server  
- 온프레미스 물리 서버 서비스 실행 화면  
- VPN 연결 및 서버 상태 확인 화면  

본 캡처들은  
프로젝트의 실제 동작 구조와 구현 결과를 시각적으로 확인하기 위한 자료로 사용됩니다.
