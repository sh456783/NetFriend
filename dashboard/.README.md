# Web Dashboard  
FastAPI × React 기반 서버 모니터링 대시보드

이 폴더는 EC2 보안 서버, Auto Scaling으로 생성된 복제 인스턴스,  
그리고 온프레미스 물리 서버에서 수집한 데이터를 웹 UI로 확인할 수 있도록 구성된 대시보드입니다.  
Suricata IDS 로그, CloudWatch 메트릭(EC2 + 물리 서버), EC2 제어 기능을 한 화면에서 관리할 수 있습니다.

---

## 주요 기능

### ● IDS 로그 모니터링
- Suricata가 생성한 `eve.json` 이벤트를 FastAPI를 통해 수집  
- 탐지 시간, 시그니처, 출발지/목적지 등 기본 탐지 정보 표시

### ● 시스템 메트릭 모니터링 (EC2 + 물리 서버)
- EC2 인스턴스 CPU 메트릭을 CloudWatch에서 가져와 그래프로 표시  
- **온프레미스 물리 서버도 CloudWatch Agent를 설치하여 CPU 사용률을 동일한 방식으로 전송**  
  → 대시보드에서 EC2 인스턴스와 똑같이 확인 가능  
- Auto Scaling으로 생성된 복제 인스턴스도 자동으로 목록에 포함되어 메트릭 조회 가능

### ● 콘솔 로그 확인
- EC2 및 Auto Scaling 인스턴스의 시스템 로그 확인 가능  
- 장애 상황 점검 및 상태 확인에 사용

### ● EC2 인스턴스 제어
- Start / Stop / 상태 조회 기능 제공  
- 메인 서버뿐 아니라 Auto Scaling 인스턴스도 동일하게 제어 가능

### ● IP 차단 관리
- Suricata 이벤트 기반 ipset 자동 차단  
- 차단된 IP 리스트 확인 및 해제 기능 제공

## 참고
- Nginx Reverse Proxy 환경 기준으로 배포되었습니다.  
- 로컬 개발 시 React(3000), FastAPI(8000) 포트를 사용합니다.  
- **물리 서버 CPU 지표는 CloudWatch Agent를 통해 AWS로 전송되며, 대시보드에서 EC2와 동일하게 표시됩니다.**  
- Auto Scaling 인스턴스도 자동으로 추가되어 동일한 방식으로 모니터링할 수 있습니다.
