# internal_security [Custom IPS & Login Security]  
Python 기반 내부 보안 · 자동 차단 시스템

이 폴더는 **서버 내부 보안 강화를 위해 직접 구현한 커스텀 IPS 및 로그인 보안 시스템**을 정리한 폴더입니다.  
Suricata IDS 탐지 결과와 로그인 실패 이벤트를 기반으로 **ipset을 활용한 커널 레벨 IP 차단**을 수행하며
차단 이력은 DB에 저장되어 **웹 대시보드(server-monitor)와 연동**됩니다.

Fail2Ban의 동작 원리를 참고하되 실제 차단 로직은 Python으로 직접 구현하여 **속도·제어·확장성**을 개선했습니다.

---

## 🔐 내부 보안 처리 알고리즘 (Internal Security Algorithm)

<img src="../screenshots/architecture/internal_security_algorithm.png" width="800"/>

내부 보안 알고리즘은  
**침입 탐지(IDS) → 판단 → 차단(IPS) → 관리**의 흐름으로 동작합니다.

처리 흐름은 다음과 같습니다.

- 네트워크 트래픽 또는 로그인 이벤트 발생  
- Suricata IDS 또는 로그인 보안 로직에서 이벤트 감지  
- 이벤트 유형 및 위험도(severity) 기준으로 대응 방식 결정  

동작 분기  
- 저위험 이벤트  
  → 로그 기록 및 대시보드 알림만 수행  
- 고위험 이벤트  
  → ipset을 통한 즉시 IP 차단  
  → 차단 정보 DB 저장 (TTL 포함)  

차단 이후  
- TTL 만료 시 자동 해제  
- 해제 시 ipset 및 DB 동기화 제거  
- 모든 상태 변화는 server-monitor 대시보드에 실시간 반영  

이 구조를 통해  
로그 파싱 기반 방식보다 빠르고,  
대규모 트래픽 환경에서도 안정적인 내부 보안 처리가 가능하도록 구성했습니다.

## 주요 구성 요소

### ● IP 차단 관리 시스템 (DB 기반)
- 자동 차단 / 수동 차단 발생 시 차단 정보를 DB(SQLite)에 저장  
- 차단 IP, 차단 사유, 생성 시간, 만료 시간(TTL), 차단 주체(actor) 기록  
- TTL 만료 시 자동 해제 → DB + ipset 동기화 제거  
- 모든 차단 정보는 웹 대시보드에서 실시간 조회 및 관리 가능

---

### ● 로그인 보안 (실패 누적 기반 차단)
- 로그인 시도 실패 기록을 Python 로직으로 누적 관리  
- **일정 시간 내 로그인 실패 5회 이상 발생 시 자동 차단**  
- 차단 시 ipset을 통해 커널 레벨에서 즉시 트래픽 차단  
- 차단 후 실패 기록 초기화 → 불필요한 중복 차단 방지  
- Fail2Ban 대비:
  - 로그 파싱 불필요
  - 서버 부하 감소
  - TTL 및 차단 이력 DB 관리 가능

---

### ● IPS 자동 차단 (Suricata 연동)
- Suricata IDS가 네트워크 트래픽을 분석하여 공격 이벤트 생성  
- 탐지된 이벤트의 **위험도(severity)** 를 기준으로 차단 정책 적용

#### 차단 정책
- **저위험 공격 (severity 0~2)**  
  → 경고만 표시 (차단 미적용)
- **고위험 공격 (severity ≥ 3)**  
  → ipset 자동 차단 + DB 저장 (기본 6시간)

#### 탐지 및 대응 공격 유형
- Port Scan / SYN Scan  
  → 정찰 단계 공격으로 분류, 경고만 표시  
- SSH Brute Force  
  → 로그인 보안 시스템에서 우선 탐지 및 차단  
- SQL Injection  
  → 고위험 공격, 자동 차단 적용  
- XSS 공격  
  → 고위험 공격, 자동 차단 적용  

차단된 IP는 즉시 **웹 대시보드의 IP 차단 목록에 반영**됩니다.

---

## 기술적 특징

- ipset 기반 커널 레벨 차단  
  → iptables 룰 다중 생성 방식보다 빠르고 효율적  
- TTL 기반 자동 해제 로직 구현  
  → 관리 개입 없이 차단 자동 해제  
- 모든 차단 이벤트를 DB로 관리  
  → 차단 이력 추적, 시각화, 정책 확장 용이  
- server-monitor 대시보드와 연동  
  → 차단 IP 조회 / 연장 / 해제 / 수동 차단 가능
