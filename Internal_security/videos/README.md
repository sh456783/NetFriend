## 🎥 Attack Detection Demo

이 영상은 **기존 Fail2ban**과 **커스텀 ipset 기반 Fail2ban**의  
**공격 탐지 및 IP 차단 속도**를 비교한 데모 영상입니다.

동일한 공격 트래픽 환경에서  
각 방식이 공격을 얼마나 빠르게 차단하는지 확인할 수 있습니다.
